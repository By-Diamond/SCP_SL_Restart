# SL Restart · SCP:SL 服务器重启提示

![预览](images/preview.png)

**左上角实时显示各服实时人数**，某服务器一旦重启，立刻弹一条**红色「[x服] 重启」提示**，10 秒后自动消失。
重启时**点击「[x服] 重启」提示直接进服**
开启「Windows 通知」后，重启还会弹系统通知：一台服一条、**自带「进服」按钮**，点哪个进哪个。
还能顺便盯着每台服的**估算回合时长**（超过 20 分钟变黄），掐着点等保底。

显示人数、服务器名称、监控的服务器列表 都可以**自定义**

- **单文件绿色版**：双击就能跑，不用安装，所有数据都在 exe 同目录
- **无控制台窗口**：安静地待在右下角托盘里
- **鼠标穿透**：人数条不挡操作，不影响你开枪、转视角；「重启提示」不穿透——它是拿来点的
- **不用账号、不用 API Key**：直接本地查询服务器，不上传任何数据

## 下载 & 运行

1. 到 [**Releases**](https://github.com/By-Diamond/SCP_SL_Restart/releases) 下载最新的 `SL Restart.exe`
2. 双击运行 → 右下角托盘出现红底「SL」图标，左上角出现人数条，就说明在工作了
3. 想关掉：托盘图标 **右键 → 退出程序**

> **第一次运行，Windows 可能弹蓝色警告**（「Windows 已保护你的电脑」）：
> 点「更多信息」→「仍要运行」即可。这是个人小工具、没买代码签名证书的正常现象，不是程序有问题。
>
> **杀毒软件报毒**多半也是同一个原因（PyInstaller 打包的程序常见误报），可以加信任；
> 如果你不放心，可以只下载源码、自己按文末「自己打包」跑起来。

## 界面说明

| 位置 | 样子 | 说明 |
|---|---|---|
| 左上角 `(10,10)` | 白色 16px：`[1服] 41人 21:00  |  [3服] -人  |  [5服] 19人 等待2人` | 常驻显示，每秒刷新；`21:00` 是**估算回合时长**（超过 20 分钟变黄），`等待2人` / `开局0:45` 是开局估算 |
| 左上角 `(10,48)` | 红色粗体：`[3服] 重启` | 检测到重启时弹出，10 秒后自动淡出；**可点击**，点一下经 Steam 直连**晚重启**的那台服。位置始终跟在人数条正下方，不独立摆放；可在「提醒设置…」里关掉 |

- `-人` 表示这台服**暂时查不到**（打不通 / 维护中 / 对方关了查询），**不是** 0 人。
- **怎么判断重启**（两种情况都算）：
  1. 人数**从大于 0 掉到 0** —— 人全掉光，服务器重启后的典型现象；
  2. 人数**从大于 0 变成查不到** —— 服务器突然下线。为了不被网络抖动骗到，
     要**连续 2 次查询失败**（约 2 秒）才判掉线。
- **估算回合时长**（A2S 查不到真实回合状态，所以是本地估算）：
  1. 人数**达到门槛**（默认 2 人）先显示 `开局0:45`，倒计时结束才从 `0:00` 开始计时；
  2. 人数不够时显示 `等待2人`；门槛人数和等待秒数可在「提醒设置…」里改；
  3. 倒计时期间**人数掉回门槛以下 / 查询失败 / 暂停监控 / 长时间没采样** → 取消倒计时，重新等；
  4. 进入计时后**降到 1 人仍继续**；人数归零或确认掉线 → 重置；
  5. 暂停期间点「立即刷新」也不会推进计时；超过 **20 分钟变黄**。
- 0 人 / 离线的服不显示时长，不占地方。
- **多台服一起重启**：服名会并排显示成一条，例如 `[1服] [3服] 重启`，不会互相盖掉；
  10 秒内又有服重启，就接着并进去，并把倒计时重新数满 10 秒。
  这时点击提示进的是**晚重启**的那台（最后重启 = 进服排队最靠前）。
- **一键进服的原理**：点击提示 = 执行 `steam://connect/IP:端口`，由 Steam 接管——
  游戏没开会自动启动并直连；正在别的服玩会先排队，回主菜单后自动连过去。
  如果点了没反应，多半是 Steam 没在运行。
- **重启的 Windows 通知**（「提醒设置…」里开启后）：一台服一条、各带一个「进服」按钮，
  点按钮或通知本体直接连**那台**服，想进哪个点哪个。
- **灵动岛同步卡片**：装了 NotchPeninsula 灵动岛时，同一条提醒会以**带「进服」按钮的卡片**弹在
  岛上（推本机 `127.0.0.1:47300`，没装/没开就静默跳过），点按钮或卡片本体直达那台服；
  同一时刻的系统通知不会再被灵动岛重复镜像一遍；卡片停留 **10 秒** 再收起。
- **自动挤服**：勾选若干台服并设人数阈值（留空 = 人数上限，即出现空位），开启后每秒检测，
  任意一台人数低于阈值就按顺序自动 `steam://connect` 进第一台、弹 Windows 通知，
  然后**自动关闭**——每次开启只进一次，想再挤就再勾上。

## 托盘菜单（右键图标）

| 菜单项 | 作用 |
|---|---|
| **显示人数条** | 勾选 = 显示（默认开）；也可以**左键单击托盘图标**快速切换显隐。**关掉的状态会记住**，重启程序、服务器重启、编辑清单都不会自己冒出来 |
| **显示回合时长** | 勾选 = 人数后面跟**估算回合时长**（默认开）；哪些服显示在「编辑服务器清单…」里单独勾 |
| **移动人数条** | 勾选 = 解锁人数条拖动（出现蓝框），拖完自动保存位置；取消勾选恢复鼠标穿透。**重启提示会跟着一起动** |
| **暂停监控 / 继续监控** | 临时停止查询（比如网络不好、不想刷了）；暂停期间时长也冻结 |
| **立即刷新** | 马上重查一轮 |
| **自动挤服** | 勾选后配置要挤的服：可勾清单里的，也可添加自定义地址（互不影响），每台可设人数阈值（留空 = 人数上限）；任意勾选的服人数低于阈值就按顺序自动进第一台并弹通知，**进到即自动关闭** |
| **编辑服务器清单…** | 增删服务器：填 `IP:端口` + 服名，还能逐台勾「显示时长」，拖行首 `≡` 可排序，确定后立即生效 |
| **提醒设置…** | 「启用重启提示框」（默认开，关掉就不弹左上角红字），开局估算的**门槛人数 / 等待秒数**；分别开启重启提示音和 Windows 通知，选择自定义音频、调节音量、试听或测试通知（声音和通知默认都关） |
| **第三方适配** | 默认关闭；勾选后在本机开一个只读数据端口（`127.0.0.1:17777`，`GET /snapshot` 返回 JSON 快照：服务器名/人数/上限/在线状态/估算回合时长），供灵动岛插件等第三方程序读取；数据都是程序已算好的，第三方自己不做查询。端口可在 `settings.json` 的 `api_port` 改；开/关状态会记在 `settings.json` 里 |
| **开机自启** | 勾选即开机自动运行，取消即关闭（只改你自己电脑的启动项） |
| **关于** | 程序版本、项目与作者链接 |
| **退出程序** | 完全退出 |

鼠标停在托盘图标上，可以直接看到当前人数汇总。

> 默认清单里已经填好 3 台服（Horizon服务器），开箱即用；要换成自己的服，用「编辑服务器清单…」改就行。

## 它会生成哪些文件

程序是**绿色 / 便携**的：所有文件都写在 **exe 所在目录**，换个文件夹或拷到别的电脑带走即可。

| 文件 | 内容 |
|---|---|
| `settings.json` | 你的服务器清单和界面参数（托盘改清单会写回这里） |
| `history.csv` | 每秒一行的人数记录，可以用 Excel 打开看历史 |
| `latest.md` | 最近一次的人数快照表格 |
| `events.log` | 只记事件：重启 / 上线 / 离线 |
| `SL_Restart.log` | 程序自身的运行日志（反馈问题时把它发给我） |

不想要历史数据，直接删掉 `history.csv` 就行，程序会自动重建。

## 常见问题

**Q：提示「[x服] 重启」了，但服务器其实没重启？**
判定是「人数从 >0 掉到 0」或「人数从 >0 变成查不到」。玩家同时全退、或者网络正好抽风（已经做成连续 2 次失败才判掉线）都可能被算成一次；人数回来后一切正常，不用管。

**Q：为什么显示「等待2人」/「开局0:45」，或者时长一直停在 0:00 不走？**
回合时长是**本地估算**（人数查询拿不到真实回合状态）：人数先达到门槛（默认 2 人）才开始 `开局0:45` 倒计时，倒计时结束才从 `0:00` 计时。
人数不够就停在 `等待2人`；人数 0 / 查不到 / 暂停时会冻结，倒计时阶段遇到这些情况还会直接取消、重新等。
门槛人数和等待秒数都能在「提醒设置…」里改。另外程序自己重启（比如重启电脑、更新版本）后是从 `0:00` 重新算的，不会去翻 `history.csv` 补历史。

**Q：为什么某台服没有时长？**
两种可能：托盘菜单里「显示回合时长」没勾（全局），或者「编辑服务器清单…」里这台服的「显示时长」没勾（逐台）。

**Q：会不会挡到我玩游戏？**
人数条是鼠标穿透的，点击、射击都不受影响。重启提示占据的那一小块（左上角第二行）可以点——这是故意的，点它就是进服；嫌碍眼可以在 `settings.json` 里把 `restart_seconds` 调小，或忽略它等它自己淡出。

**Q：能不能只看我的服务器 / 加更多服？**
可以。托盘右键 →「编辑服务器清单…」，任意增删，填 `IP:端口` 和服名即可。

**Q：别的游戏能用吗？**
只要服务器支持 Steam 的 A2S 查询协议（SCP:SL、CS、求生之路等）就能用。填**游戏端口**（SCP:SL 默认是 7777）。

**Q：占性能 / 流量吗？**
每台服每秒一个几十字节的 UDP 包，实测单次查询几十毫秒，基本不占 CPU 和带宽。

**Q：重启通知上的「进服」按钮点不动？**
按钮靠程序自动注册的 `slrestart://` 协议（首次发通知时写入**当前用户**注册表，不需要管理员）。如果安全软件清理过注册表、或把 exe 挪了位置，再收一条重启通知就会自动重新注册；也可以在「提醒设置…」里点一次「测试通知」触发。

**Q：换电脑后配置还在吗？**
在。整个文件夹拷过去就行（配置、历史记录都在 exe 旁边）。

pip install -r requirements-build.txt

build.bat notest                   # 跳过自检，直接编译

> 两个 bat 都是**双击就行**：会自动找 Python、缺依赖才装、编译完把旧 exe 让位（旧版正在跑也能换）。
> 它们存成 GBK 编码（跟中文 Windows 控制台一致），用编辑器改的话注意别存成 UTF-8，
> 否则中文提示会变乱码、个别行还可能被 cmd 误当成命令。

python tests\verify_alerts.py      # 提示音 / Windows 通知（离屏）
python tools\shot.py               # 离屏出图，检查覆盖窗和关于窗口外观
