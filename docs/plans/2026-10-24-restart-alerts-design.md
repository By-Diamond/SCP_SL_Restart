# 重启声音与 Windows 通知设计

用户已确认：新增「提醒设置」，提示音和 Windows 通知分别开关，默认均关闭。支持 MP3/WAV 自定义音频、音量调整和试听。

## 行为

检测到重启时，保留现有红色悬浮提示，并按设置播放声音、发送 Windows 通知。同一轮多台服务器重启只播放一次声音、发送一条合并通知。设置写回 settings.json，取消设置不生效。

## 实现

- 新增 alerts.py，管理 Qt 音频播放和异步 Windows 原生通知。音频留空时使用 Windows 系统提示音文件，自定义文件使用绝对路径；文件丢失或解码失败记日志并回退系统提示音。通知通过 Windows PowerShell 调用 WinRT，XML 使用标准库转义，脚本以编码参数传递，避免字符串注入。通知自身保持静音。
- 新增 alert_dialog.py，提供两个开关、音频选择、音量滑块、试听和测试通知。提醒文件不拷贝入程序目录，界面和 README 明示移动或删除文件后需要重选。
- config.py 增加四项兼容旧配置的设置；sl_restart.py 在事件汇总处调用提醒控制器。
- 播放与通知均异步，不阻塞轮询或界面。进程错误、超时和音频错误记日志。

## 验证

离屏测试配置默认值与读写、设置取消与确认、自定义音频选择与音量、缺失文件回退、声音和通知独立开关、多服合并、异步通知参数与 XML 转义。运行原有逻辑、拖动和界面回归，再打包 Windows 可执行文件。
